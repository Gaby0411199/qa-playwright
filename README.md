# 🚀 QA Automation Project - Playwright

## 📌 Descripción
Proyecto de automatización de pruebas web utilizando Playwright.  
Este proyecto valida el flujo de login de una aplicación web, cubriendo escenarios positivos y negativos.

---

## 🧪 Casos de prueba

- ✅ Login válido (usuario correcto)
- ❌ Login inválido (usuario incorrecto)
- ⚠️ Validación de mensajes de error

---

## 🧰 Tecnologías utilizadas

- Playwright
- JavaScript
- Node.js

---

## 📁 Estructura del proyecto


qa-playwright/
├── tests/
│ └── login.spec.js
├── pages/
│ └── LoginPage.js
├── README.md
├── package.json


---

## ▶️ Cómo ejecutar el proyecto

1. Instalar dependencias:


npm install


2. Ejecutar tests:


npx playwright test --headed


---

## 🎯 Buenas prácticas aplicadas

- Page Object Model (POM)
- Separación de lógica y tests
- Uso de assertions

Este proyecto fue desarrollado como práctica de automatización QA, demostrando habilidades en testing automatizado y buenas prácticas de desarrollo.
